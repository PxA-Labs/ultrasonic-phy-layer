Detailed Description

Public C API for the Soundwave Ultrasonic Physical Layer (PHY) library.

This header defines the stable C ABI callable from Flutter via dart:ffi or from any host language (C/C++, Rust, Python, Go). All functions use strict C linkage with fixed-width C-compatible types.

◆ sw_config_validate()

int sw_config_validate ( sw_config_t cfg)

Validate a modem configuration before it reaches the DSP core.

Every sw_* function that takes an sw_config_t calls this first, so invalid settings are rejected with SW_ERR_BAD_PARAM instead of driving allocation sizes or loop bounds. A zero value means "use the module default".

Accepted ranges (0 = default):

  • modulation: 0 (CSS) or 1 (OFDM); equalizer, ofdm_modulation: 0 or 1
  • sample_rate: 8000..192000 Hz
  • all float fields finite; threshold, carrier_freq, bandwidth, symbol_duration >= 0; amplitude in [0, 1] (0 = default 0.8)
  • CSS: sf 6..10; carrier_freq and bandwidth <= sample_rate / 2; symbol_duration <= 1 s (ignored by CSS). With modulation 0 the band carrier_freq +/- B/2 must lie in (0, fs/2] and 2^sf / B <= 1 s, where B = fs / round(fs / bandwidth)
  • OFDM: num_subcarriers a power of two in 16..4096; cp_length <= num_subcarriers; num_pilots <= num_subcarriers / 2; when modulation == 1, the band [carrier_freq - bandwidth/2, carrier_freq + bandwidth/2] (defaults 19000 / 2000 Hz) must lie above DC and at least one subcarrier spacing (fs/N) below Nyquist, and hold at least 4 subcarriers after one guard bin at each edge. sw_ofdm_modulate/demodulate/equalized_symbols check the band even when modulation is 0.
Parameters
cfgConfiguration to check.
Returns
SW_OK if valid, SW_ERR_BAD_PARAM otherwise.

◆ sw_ofdm_equalized_symbols()

int sw_ofdm_equalized_symbols ( const float * samples,
size_t sample_len,
sw_config_t cfg,
float * iq,
size_t * num_points )

Demodulates an OFDM frame and returns the equalized data-subcarrier constellation points (for constellation diagrams and EVM).

Runs the same detection, CFO correction, channel estimation and ZF/MMSE equalization as sw_ofdm_demodulate(), but outputs the complex points that feed the hard demapper instead of bits. Points are unit-energy for the configured mapping: BPSK at +/-1, QPSK at (+/-1 +/-j)/sqrt(2).

Parameters
samplesPointer to input float PCM audio samples (frame-aligned).
sample_lenNumber of input audio samples.
cfgPHY configuration struct; cfg.modulation must be 1 (OFDM).
iqPre-allocated output buffer of 2 * (*num_points) floats, interleaved I0, Q0, I1, Q1, ...
num_pointsInput: capacity in complex points (> 0). Output: number of points written. Points are in symbol order, then data-subcarrier order; a frame with more points than the capacity is truncated (not an error).
Returns
SW_OK (0) on success, or negative sw_error_t code.

◆ sw_ofdm_modulate()

int sw_ofdm_modulate ( const uint8_t * bits,
size_t bit_len,
sw_config_t cfg,
float * samples,
size_t * sample_len )

Modulates bit array into OFDM audio samples (IDFT + cyclic prefix).

Data and pilot subcarriers occupy only the band [carrier_freq - bandwidth/2, carrier_freq + bandwidth/2] (default 18-20 kHz); all other bins are zero and symbol boundaries are raised-cosine cross-faded. Output length is (2 + ceil(bit_len / bits_per_symbol)) * (N + cp) + cp / 2 samples. Output level: the frame is scaled by one gain so that its peak max |sample| equals cfg.amplitude (0 = 0.8); output is therefore always within [-1, 1] and can be played or written to PCM without clipping.

Parameters
bitsPointer to input bit stream array.
bit_lenNumber of input bits.
cfgPHY configuration struct.
samplesPre-allocated output float sample buffer.
sample_lenInput: capacity, Output: written sample count.
Returns
SW_OK (0) on success, or negative sw_error_t code.
