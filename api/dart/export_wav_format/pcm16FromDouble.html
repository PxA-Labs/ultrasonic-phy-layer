Quantises one sample in -1, 1 to a signed 16-bit value.

Uses the 2^15 scale (the inverse of the /32768 used when reading) so a round trip is accurate to half an LSB; +1.0 clips to 32767.

Implementation

int pcm16FromDouble(double s) {
  if (s.isNaN) return 0;
  final v = (s * 32768.0).round();
  return v.clamp(-32768, 32767);
}
