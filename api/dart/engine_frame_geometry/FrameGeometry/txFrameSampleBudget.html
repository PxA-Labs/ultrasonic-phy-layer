Sample budget for one transmitted frame that must carry at least minPayload bytes: targetFrameAirtimeSeconds, stretched to twice the smallest such frame when that alone takes more than half of it, and never above SoundwaveNative.maxFrameSamples. The stretch matters for slow CSS settings (SF10 / 2 kHz: a 12-byte link frame already takes ~25 s, mostly preamble and FEC): frames there stay at most twice the minimum, so at least half of their airtime carries payload.

Implementation

int txFrameSampleBudget({int minPayload = 1}) {
  final smallest = samplesForFrameBytes(_frameBytes(minPayload));
  final target = (targetFrameAirtimeSeconds * sampleRate).floor();
  return math.min(
      SoundwaveNative.maxFrameSamples, math.max(target, 2 * smallest));
}
