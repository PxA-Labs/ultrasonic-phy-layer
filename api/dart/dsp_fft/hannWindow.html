Periodic (DFT-even) Hann window: wn = 0.5 - 0.5 cos(2 pi n / N).

The periodic form is the standard choice for spectral analysis: its coherent gain is exactly 0.5 and a bin-centred tone leaks into exactly its two neighbouring bins.

Implementation

Float64List hannWindow(int n) {
  if (n <= 0) throw ArgumentError.value(n, 'n', 'must be positive');
  final w = Float64List(n);
  for (var i = 0; i < n; i++) {
    w[i] = 0.5 - 0.5 * math.cos(2 * math.pi * i / n);
  }
  return w;
}
