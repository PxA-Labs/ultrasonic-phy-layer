SpectrumAnalyzer

SpectrumAnalyzer class

Turns a stream of audio samples into dBFS magnitude spectra.

Scaling: a full-scale sine (amplitude 1.0) centred on a bin reads 0 dBFS at that bin, i.e. bins hold the estimated sinusoid amplitude in dB.
